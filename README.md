# Vibe - AI Code Generation Platform

**Describe your dream app, and watch the AI build it in real-time.**

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://vibe-iota-eight.vercel.app/)

Vibe is an AI-powered web application that bridges the gap between idea and execution. By leveraging state-of-the-art LLMs and isolated sandbox environments, Vibe allows users—ranging from non-programmers to seasoned designers—to generate, test, and iterate on full-stack web projects simply by describing them.

Check out the live application here: [https://vibe-iota-eight.vercel.app/](https://vibe-iota-eight.vercel.app/)

## ✨ Key Features

-   **Natural Language to Code**: Describe your application in plain English (e.g., "Build a task manager with dark mode") and get a functional codebase.
-   **Live Preview & Sandbox**: Every project runs in an isolated E2B sandbox, providing a real-time, interactive preview of the generated app.
-   **Code Transparency**: Switch between "Preview" and "Code" modes to inspect every file, component, and style generated by the AI.
-   **Interactive Iteration**: Refine your project through a chat interface (e.g., "Change the primary color to blue" or "Add a login button").
-   **Secure Authentication**: Powered by Clerk for a seamless and secure sign-up/sign-in experience.
-   **Robust Background Processing**: Uses Inngest to manage complex, long-running AI code generation tasks reliably.

-   **Framework**: [Next.js](https://nextjs.org/) (React)
-   **Styling**: [Tailwind CSS](https://tailwindcss.com/)

-   **Runtime**: [Node.js](https://nodejs.org/)
-   **ORM**: [Prisma](https://www.prisma.io/)
-   **Database**: [PostgreSQL](https://www.postgresql.org/)
-   **Authentication**: [Clerk](https://clerk.com/)

### AI & Infrastructure
-   **AI Model**: [OpenAI GPT-4o](https://openai.com/)
-   **Background Jobs**: [Inngest](https://www.inngest.com/)
-   **Code Sandboxing**: [E2B](https://e2b.dev/)

## 🏗️ How It Works (The Vibe Workflow)

1.  **Input**: The user describes a project in the dashboard.
2.  **Orchestration**: A tRPC procedure saves the request and triggers an **Inngest** background function.
3.  **Generation**: The AI Agent (GPT-4o) plans the architecture and uses specialized tools to create files and run terminal commands (e.g., `npm install`).
4.  **Sandbox Execution**: The code is deployed to an **E2B Sandbox**.
5.  **Feedback Loop**: The user views the live preview and can request further modifications, restarting the generation cycle for specific components.

## ⚙️ Getting Started

### Prerequisites
-   Node.js (v18+)
-   PostgreSQL instance
-   API Keys for OpenAI, Clerk, E2B, and Inngest

### Installation

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/your-username/vibe.git
    cd vibe
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Environment Setup**:
    Create a `.env.local` file in the root directory and add the following placeholders (do not commit your actual keys):
    ```env
    # Database
    DATABASE_URL="postgresql://..."

    # Clerk Auth
    NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
    CLERK_SECRET_KEY=

    # AI & Sandboxing
    OPENAI_API_KEY=
    E2B_API_KEY=

    # Inngest
    INNGEST_EVENT_KEY=
    INNGEST_SIGNING_KEY=
    ```

4.  **Database Migration**:
    ```bash
    npx prisma migrate dev
    npx prisma generate
    ```

5.  **Run Development Server**:
    ```bash
    npm run dev
    ```
    Visit http://localhost:3000 to see the app.
